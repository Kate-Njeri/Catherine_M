The Challenge

Global Logistics Inc. executives lacked real-time visibility into operations across their 12 distribution centers. Monthly reports were outdated by the time they reached leadership, and critical issues like capacity bottlenecks or delivery delays were discovered days after they occurred. The company needed a single source of truth that updated in real-time.

My Approach

1

Data Architecture Design

Designed a star schema data warehouse in PostgreSQL with fact tables for orders, shipments, and inventory, and dimension tables for time, location, product, and carrier. Implemented incremental ETL loads every 15 minutes.

2

Live Data Pipeline

Built Python scripts using SQLAlchemy and Apache Kafka to stream data from SAP ERP, WMS, and TMS systems into the warehouse. Added data quality checks with Great Expectations to catch anomalies before they reached the dashboard.

3

Dashboard Development

Created 5 interconnected Tableau dashboards: Executive Summary, Operations Detail, Financial Metrics, Quality Control, and Predictive Alerts. Each dashboard supports drill-down from corporate level to individual facility and SKU.

4

Alert System

Implemented threshold-based alerts via Slack and email for KPIs falling outside acceptable ranges. Executives receive morning briefings with overnight performance summaries and exception reports.

Key Results

  • Real-time visibility — executives now see operations status updated every 15 minutes instead of monthly
  • 97% on-time delivery — up from 85% by catching bottlenecks before they escalated
  • $400K saved annually — reduced expedited shipping through proactive capacity management
  • 20 hours/week saved — eliminated manual report compilation across 12 facilities

Dashboard Features

The executive dashboard includes several innovative features designed for operational decision-making:

  • Capacity Heatmap: Visual grid showing utilization rates across all 12 centers with color-coded urgency levels
  • Delivery Performance Tracker: Real-time map view of in-transit shipments with ETA predictions
  • Cost Variance Analysis: Automated comparison of actual vs. budgeted costs by facility and product line
  • Predictive Alerts: ML-powered warnings for potential delays based on weather, traffic, and historical patterns

Technical Stack

The solution uses a modern data stack optimized for speed and reliability:

  • Data Layer: PostgreSQL data warehouse with TimescaleDB extension for time-series optimization
  • Streaming: Apache Kafka for real-time event streaming from operational systems
  • ETL: Python scripts with Pandas and SQLAlchemy, orchestrated by Apache Airflow
  • Visualization: Tableau Server with embedded analytics and row-level security
  • Alerts: Python microservice integrating with Slack API and SendGrid
