The Challenge

TechFlow Solutions was struggling with inventory mismanagement across 5 distribution centers. Overstock was tying up $3.5M in working capital, while stockouts were causing $800K in lost revenue annually. The existing reorder point system was purely reactive and could not account for seasonality, promotions, or supply chain disruptions.

My Approach

1

Data Collection & Integration

Aggregated 3 years of historical sales data, supplier lead times, and external factors (weather, holidays, competitor pricing) into a unified data warehouse using SQL and Python ETL pipelines.

2

Feature Engineering

Created 47 predictive features including rolling averages, seasonality indices, promotional lift factors, and supplier reliability scores. Used PCA to reduce dimensionality while preserving 95% of variance.

3

Model Development

Tested multiple algorithms (ARIMA, Prophet, XGBoost, LSTM) and selected an ensemble approach combining XGBoost for short-term and Prophet for long-term forecasts. Achieved 94% accuracy on holdout data.

4

Deployment & Monitoring

Deployed the model via a Flask API with automated retraining every 2 weeks. Built a Tableau dashboard for inventory managers to review recommendations and override when needed.

Key Results

  • 35% reduction in overstock — freed up $1.2M in working capital within 6 months
  • 60% reduction in stockouts — improved customer satisfaction scores by 18 points
  • 25% decrease in emergency freight costs — fewer rush orders needed
  • 12 hours/week saved — automated what was previously manual spreadsheet analysis

Technical Architecture

The system runs on a microservices architecture with three main components:

  • Data Pipeline: Apache Airflow orchestrates daily ETL from ERP (SAP), WMS, and external APIs into PostgreSQL
  • ML Service: Python/Flask API serving predictions with model versioning via MLflow
  • Frontend: Tableau dashboards + a lightweight React app for inventory managers to approve/reject recommendations

Lessons Learned

The biggest challenge was not the model accuracy — it was change management. Inventory managers were skeptical of "black box" recommendations. We solved this by adding explainability features (SHAP values) and allowing manual overrides with feedback loops that improved the model over time.
